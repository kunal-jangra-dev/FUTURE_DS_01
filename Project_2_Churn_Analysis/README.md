# Customer Churn Prediction Using Machine Learning

This project predicts customer churn using machine learning techniques on the Telco Customer Churn dataset.

The goal of this project is to identify customers who are likely to leave a telecom service based on customer demographics, account information, and service usage patterns.

---

## Project Workflow

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Encoding Categorical Variables
- Train-Test Split and Feature Scaling
- Model Training
- Model Evaluation
- Feature Importance Analysis

---

## Machine Learning Models Used

- Logistic Regression
- Random Forest Classifier
- Gradient Boosting Classifier

---

## Evaluation Metrics

The models were evaluated using:

- Accuracy Score
- ROC-AUC Score
- Classification Report
- Confusion Matrix
- ROC Curve

---

## Key Insights

- Customers with month-to-month contracts showed higher churn rates.
- Customers with lower tenure were more likely to churn.
- Contract type, tenure, and monthly charges were among the most important churn predictors.
